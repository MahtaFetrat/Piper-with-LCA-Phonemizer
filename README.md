
# Enhanced PiperTTS with Lightweight Context-Aware Phonemization (Piper + LCA)

This repository contains the official implementation of the system proposed in the paper:

***Beyond Unified Models: A Service-Oriented Approach to Low-Latency, Context-Aware Phonemization for Real-Time TTS***

We present an enhanced Persian Text-to-Speech (TTS) pipeline built on top of **PiperTTS**, augmented with a **Lightweight Context-Aware (LCA) phonemization layer** that improves pronunciation accuracy—especially for linguistically ambiguous phenomena such as **Ezafe**—while preserving **real-time performance**.

The repository is **forked from the original PiperTTS**, maintaining its efficient design, and extended with modular components for **context-sensitive phonemization**, **neural Ezafe prediction**, and **service-oriented integration**.

---

## Overview

Modern end-to-end TTS models often rely on unified architectures that trade interpretability and latency for accuracy. In contrast, this work explores a **service-oriented design**, where lightweight neural models selectively enhance symbolic phonemization only where context is required.

Our approach:

* Preserves the **speed and compactness** of PiperTTS
* Introduces **task-specific neural models** only when necessary
* Improves **phonemization accuracy for Persian**, particularly in Ezafe disambiguation
* Remains suitable for **real-time and on-device TTS**

> **Key idea:** Not all phonemization decisions require heavy neural models—context-aware refinement can be applied selectively and efficiently.

## Repository Structure

```text
.
├── experiments/
│   ├── tts_inference.py          # Scripts for synthesizing audio using different TTS setups
│   ├── tts_evaluation.ipynb      # Evaluation notebook for phonemization quality and RTF
│   ├── spacy_experiments.ipynb   # Experiments with SpaCy POS tagger for Ezafe detection
│   └── albert_experiments.ipynb  # Experiments using distilled ALBERT model
│
├── sample_outputs/
│   ├── glow/                      # Audio generated by GlowTTS
```

We provide a **Google Colab notebook** for end-to-end inference with the enhanced **Piper + Lightweight Context-Aware (LCA) phonemization** pipeline.

The notebook walks through the complete process, including:

* Environment setup and dependency installation
* Building and configuring **Piper with LCA phonemization**
* Running the **context-aware phonemization service** (Ezafe-aware G2P)
* Performing **Persian TTS inference** and generating audio samples

### Ezafe Detection Model
